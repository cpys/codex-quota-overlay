# Support

Codex Quota Overlay is a volunteer-maintained community project. Support is best-effort; no service-level agreement is provided.

## Before asking for help

1. Install the latest release from the official [Releases page](https://github.com/cpys/codex-quota-overlay/releases).
2. Read [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Search existing issues and discussions.
4. Copy the in-app **short diagnostic** only. It is capped at 200 characters.

For reproducible defects, open a [bug report](https://github.com/cpys/codex-quota-overlay/issues/new?template=bug_report.yml). Use [Discussions](https://github.com/cpys/codex-quota-overlay/discussions) for setup questions and ideas. Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Never upload managed-device screenshots, long diagnostic exports, settings files, raw App Server responses, account details, tokens, private paths, source code, or conversation content.

The project supports the latest released overlay version with current Codex Desktop releases on the platforms listed in the README. Linux is out of scope while no official Codex Desktop app is available there.
