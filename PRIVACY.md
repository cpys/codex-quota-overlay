# Privacy

Last updated: 2026-08-09

Codex Quota Overlay is designed to work locally. Reading quota, locating the Codex window, positioning the overlay, and writing operational logs all happen on the user's Windows device.

## Codex data

The app starts the locally installed `codex.exe app-server` process and calls `account/rateLimits/read`. It uses the returned quota percentage, reset timestamp, and optional reset-credit metadata only to render the overlay. It does not transmit this Codex data to the project maintainer.

The app does not collect or transmit ChatGPT account details, access tokens, API keys, conversation content, conversation titles, prompts, responses, source code, file paths, screenshots, or browser cookies.

## Optional anonymous usage statistics

Telemetry is disabled in source builds unless an HTTPS endpoint is explicitly configured. A configured build asks before enabling it, and the choice can be changed from the tray menu.

When enabled, the app sends at most one `daily_active` heartbeat per 24 hours containing:

- a random installation UUID generated by this app;
- the overlay version;
- the constant platform value `windows`;
- the Windows version reported by the operating system;
- the current UI locale;
- an event timestamp and schema version.

The application payload does not include an IP address. As with any HTTPS request, the hosting and network providers may process the source IP to deliver the request and may temporarily include it in security logs. The project analytics store must not use the IP as a user identifier or copy it into analytics records.

The installation UUID is used only to estimate unique active installations. It is stored locally in `%LOCALAPPDATA%\CodexQuotaOverlay\settings.json`. Deleting that file creates a new identity on the next launch. Analytics heartbeat records are retained for no more than 90 days by the reference backend.

## Local files

- `%LOCALAPPDATA%\CodexQuotaOverlay\settings.json`: random installation ID, telemetry choice, and last successful heartbeat time.
- `%LOCALAPPDATA%\CodexQuotaOverlay\overlay.log`: short operational error summaries.

Uninstalling the app does not automatically delete these files. They can be removed manually after the app exits.

## Changes and questions

Material privacy changes will be documented in the changelog and this file. For questions, open a GitHub issue without posting account data, tokens, logs containing sensitive information, or your installation UUID.
